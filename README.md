# KEYPEE PANCH Website

Welcome to the KEYPEE PANCH project! This is a premium custom t-shirt printing website built with HTML5, CSS3 (Glassmorphism), and JavaScript.

## Getting Started

To view the website, simply open the `index.html` file in your preferred web browser.

No installation or build steps are required.

## Project Structure

- **index.html**: Home page with Hero and Features section.
- **services.html**: Products page featuring a Sidebar Filter Panel.
- **social.html**: Social media links and mock feed.
- **offer.html**: Special promotions and offers.
- **style.css**: Global styles, including the premium glassmorphism theme.
- **script.js**: JavaScript for mobile menu and filter interactions.

## Features

- **Responsive Design**: Looks great on desktop and mobile.
- **Product Filter**: Interactive filter UI on the Services page.
- **Premium Aesthetics**: Vibrant colors and modern layout.
